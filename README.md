### سؤال اول: تفاوت نسخه‌های HTTP

**تفاوت نسخه‌ها:**

- **HTTP/0.9:** ساده‌ترین نسخه HTTP بود. فقط از متد `GET` پشتیبانی می‌کرد و Header و Status Code نداشت.
- **HTTP/1.0:** قابلیت‌هایی مثل Header و Status Code اضافه شدند. معمولا برای دریافت هر منبع، یک اتصال TCP جداگانه برقرار می‌شد.
- **HTTP/1.1:** امکان استفاده مجدد از اتصال TCP با `Persistent Connection` و ارسال چند درخواست پشت سر هم با `Pipelining` فراهم شد.
- **HTTP/2:** قابلیت `Multiplexing` اضافه شد تا چند درخواست و پاسخ به صورت همزمان از یک اتصال TCP عبور کنند.
- **HTTP/3:** به جای TCP از پروتکل `QUIC` بر پایه UDP استفاده می‌کند و مشکل مسدود شدن جریان‌های دیگر هنگام گم شدن یک بسته را کاهش می‌دهد.

**چرا HTTP/3 از UDP استفاده می‌کند؟**

در HTTP/2 با اینکه چند درخواست می‌توانند همزمان ارسال شوند، همه آن‌ها از یک اتصال TCP استفاده می‌کنند. به همین دلیل اگر بسته‌ای گم شود، ممکن است بقیه درخواست‌ها هم تا دریافت دوباره آن بسته منتظر بمانند. به این مشکل `Head-of-Line Blocking` می‌گویند.

در HTTP/3 از پروتکل QUIC روی UDP استفاده شده تا جریان‌های داده مستقل‌تر باشند و گم شدن بسته مربوط به یک جریان، باعث توقف بقیه جریان‌ها نشود. همچنین QUIC کمک می‌کند اتصال سریع‌تر برقرار شود.
