<h2>سؤال اول: تفاوت نسخه‌های HTTP</h2>

<h3>تفاوت نسخه‌ها</h3>

<p><strong>HTTP/0.9:</strong> اولین و ساده‌ترین نسخه HTTP بود. فقط از متد GET پشتیبانی می‌کرد و Header و Status Code نداشت.</p>

<p><strong>HTTP/1.0:</strong> قابلیت‌هایی مثل Header و Status Code به آن اضافه شدند. معمولا برای دریافت هر منبع، یک اتصال TCP جداگانه برقرار می‌شد.</p>

<p><strong>HTTP/1.1:</strong> امکان استفاده مجدد از اتصال TCP با Persistent Connection و ارسال چند درخواست پشت سر هم با Pipelining فراهم شد.</p>

<p><strong>HTTP/2:</strong> با استفاده از Multiplexing می‌توان چند درخواست و پاسخ را به صورت همزمان روی یک اتصال TCP ارسال کرد.</p>

<p><strong>HTTP/3:</strong> به جای TCP از پروتکل QUIC بر پایه UDP استفاده می‌کند. این نسخه مشکل مسدود شدن جریان‌های دیگر هنگام گم شدن یک بسته را کاهش می‌دهد.</p>

<h3>چرا HTTP/3 از UDP استفاده می‌کند؟</h3>

<p>در HTTP/2 با اینکه چند درخواست می‌توانند همزمان ارسال شوند، همه آن‌ها از یک اتصال TCP استفاده می‌کنند. به همین دلیل اگر بسته‌ای گم شود، ممکن است بقیه درخواست‌ها هم تا دریافت دوباره آن بسته منتظر بمانند. به این مشکل Head-of-Line Blocking گفته می‌شود.</p>

<p>در HTTP/3 از پروتکل QUIC روی UDP استفاده شده تا جریان‌های داده مستقل‌تر باشند و گم شدن بسته مربوط به یک جریان باعث توقف بقیه جریان‌ها نشود. همچنین QUIC امکان برقراری سریع‌تر اتصال را فراهم می‌کند.</p>
